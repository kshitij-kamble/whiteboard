# Acceptance criteria

One section per backlog item: `## <id> — <slug>`, then numbered "User can…" outcomes.
`/arc align` checks every criterion has a home in prep.

Tag a line `@undefined` to record behaviour that is **deliberately unspecified**
(e.g. "what happens when two users drag the same shape at once @undefined").
It documents the gap; it is never a criterion and must not be built to.

For anything touching shared board state, include what a *second* user sees.
